# Button

Pill buttons. The consumer provides the label and a kind: primary, secondary, or terminal.

- Primary: `butter` fill, `on-butter` text, `body-strong`. One per view.
- Secondary: `surface` fill, 1px `line` border, `ink` text.
- Terminal: `terminal` fill, `terminal-text` label with the `❯` mark in `butter`, for actions that come from the terminal world (run, copy a command).
- Padding 10px 18px, `radius-pill`. Press scales 3%. Disabled is 45% opacity. Focus gets the ring.
- Labels are plain verbs: Join the waitlist, Copy the prompt, Open. Never "Click here".
