# Nav

The top bar of any page or app. The consumer provides the name, the sections, and the current one.

- Left: the name in `heading` serif. Middle: sections as `❯ name` in mono, lowercase. Right: one primary action or the theme switch.
- The current section gets `pink-soft` behind it, `radius-tag`. Hover gets the same fill at half strength.
- On phones the sections collapse behind a thin-line menu icon, the only icon on the page.
- Height 56px, padding `space-2` sides. Border bottom 1px `line`. The nav never floats over content.
