# Tag

Three small things that share a shape. The consumer provides the text and the kind.

- Moment tag: the moment's soft tone fill with its deep tone text, `label` style, `radius-tag`, padding 4px 10px. Selected state is the same fill with a 1px border in the mid tone. Used as the four-moment filter above the library.
- Keyword chip: `terminal` fill, `terminal-text`, mono, brackets inside: `[ LEARN ]`. Click copies the keyword.
- State pill: `radius-pill`, `mint-soft` with `moss` text for success (`it ran`), `peach-soft` with `clay` text for error with a prompt line next to it.
- Tags filter with a `base` fade. Never more than six in a row.
